RistOS 0.2.0 — обновление работающей RistOS 0.1.2 Lite на GravityCraft

В этом архиве только НОВЫЕ/ИЗМЕНЁННЫЕ файлы; НЕ удаляйте существующую папку RistOS!

Что добавлено:
- Обновлённый Rist Control: RAM, три профиля, кнопки приложений.
- Rist Article AI: самостоятельная генерация статей с Gemini API, TXT, целевой объём 10–12 тыс. символов.
- Rist Update: безопасное обновление приложений через CDN с резервным копированием.
- EEPROM, /OS.lua и системные библиотеки НЕ изменяются.

Публикация:
1. Распаковать содержимое ZIP в F:\GitHub\RistOS с объединением папок.
2. GitHub Desktop: Commit to main, Push origin.
3. Убедиться, что по адресу https://github.com/mxlednev-bit/RistOS/blob/main/Installer/Upgrade_0_2.lua отображается Lua-код.
4. В запущенной RistOS открыть MineCode IDE; создать Lua-файл и вставить содержимое Installer/RistOS_0_2_loader.lua.
5. Запустить его кнопкой Run; дождаться RistOS 0.2 installed.
6. Перезагрузить игровой компьютер (предварительно сохранив данные).

Проверка: Rist Control / Rist Article AI / Rist Update на рабочем столе.
Если Gemini API заблокирован на GravityCraft, приложение сообщит об ошибке. API-ключ не сохраняется.
Если статья вышла за рамки 10–12 тыс., она всё равно сохраняется с указанием фактической длины.

Используйте локальное резервное копирование перед обновлением. Проверка на самом GravityCraft после публикации обязательна.
