# RistOs 0.1.0 — OpenComputers (сборка на базе MineOS)

Готовая файловая система OpenComputers. Сохраняет совместимость с системными библиотеками MineOS и её приложениями. RistOs не является переписанным с нуля ядром. Первая версия — самостоятельный брендированный дистрибутив с облегчённой конфигурацией, исправлением лишней перерисовки и утилитой управления режимами.

## Что изменено

- Имя RistOs на экране запуска и в разделе «О системе»; исходные авторы MineOS указаны в обоих случаях.
- Исправлена логика обоев: если они выключены, графический движок больше не включает цикл 100 Гц. Статичные обои: фоновая перерисовка 1 раз в секунду; анимированные Stars / Snow / Rain / Lines / Sphere: обновление по таймеру 10 раз в секунду (дополнительные обновления могут происходить при действиях пользователя).
- Русский язык по умолчанию для новых пользователей, эффекты прозрачности и размытия отключены, отключены динамические обои.
- Убран перегруженный стартовый рабочий стол из 19 значков; RistOs имеет аккаунт `Rist` с файловым менеджером, IDE и панелью управления.
- Приложение «Rist Control»: свободная RAM, быстрый переход ECO / BALANCED / VISUAL, сохранение выбранного режима в пользовательских настройках.
- Оставлена существующая программа App Market, но сервис магазина может быть недоступен по независимым причинам.
- Программы из MineOS оставлены в полной версии; Lite-манифест устанавливает только базовые приложения.

Это технические изменения, а не доказательство определённого ускорения: замеров FPS и потребления RAM непосредственно на GravityCraft пока нет.

## Структура архива

- `RistOS/` — готовое дерево файлов установленной ОС.
- `Installer/Install.lua` — новая установка (Lite или Full), не удаляет и не форматирует диск.
- `Installer/Upgrade.lua` — апгрейд установленной MineOS; резервные копии в `/.ristos-backup/`, без изменения EEPROM и профилей.
- `Installer/Rollback.lua` — возврат исходных `OS.lua` и `Libraries/System.lua` из резервной копии.
- `Installer/FilesLite.lua`, `FilesFull.lua`, `UpgradeFiles.lua` — манифесты файлов с ожидаемыми размерами.
- `Installer/RistEFI.lua`, `FlashEFI.lua` — опциональная загрузочная прошивка и средство прошивки. НЕ запускайте без необходимости.
- `LICENSE_MINEOS.txt` — оригинальный текст лицензии. Исходная лицензия содержит необычную/непристойную формулировку; сохранена без изменения для атрибуции.

## GravityCraft: как получить файлы внутрь OpenComputers

1. На обычном ПК разархивируйте ZIP и разместите его содержимое в публичном GitHub-репозитории. Корень репозитория должен содержать `RistOS/`, `Installer/` и `README_RU.md`.
2. Замените `USER` и `REPO` на имя своего репозитория в адресах ниже. Для jsDelivr лучше использовать новый тег релиза, например `@v0.1.0`, вместо `@main`, чтобы CDN выдавал неизменённые файлы.
3. Если у вас уже есть установленная MineOS, сделайте резервную копию важных данных. Загружайтесь с дискеты OpenOS и используйте безопасный апгрейд (работает на записываемом HDD; сама дискета может быть read-only):

```
wget -f https://cdn.jsdelivr.net/gh/USER/REPO@main/Installer/Upgrade.lua /tmp/ristos_upgrade.lua
/tmp/ristos_upgrade.lua https://cdn.jsdelivr.net/gh/USER/REPO@main/RistOS/
```

Выберите диск с существующей MineOS, дождитесь проверки шести файлов, подтвердите `UPGRADE`, перезагрузите компьютер и откройте `/Applications/Rist Control.app/Main.lua` или создайте ярлык.

Если возникли неполадки, загрузитесь с дискеты OpenOS и запустите откат:

```
wget -f https://cdn.jsdelivr.net/gh/USER/REPO@main/Installer/Rollback.lua /tmp/ristos_rollback.lua
/tmp/ristos_rollback.lua
```

Процедура возвращает исходные системные Lua-файлы из `/.ristos-backup/`; пользовательские данные и EEPROM не меняются.

**Для нового чистого HDD** (если MineOS ранее не ставили):

```
wget -f https://cdn.jsdelivr.net/gh/USER/REPO@main/Installer/Install.lua /tmp/ristos_install.lua
/tmp/ristos_install.lua https://cdn.jsdelivr.net/gh/USER/REPO@main/RistOS/ lite
```

Для полного варианта замените `lite` на `full`. Эти команды скачивают файлы на выбранный HDD, **но не меняют EEPROM**, поэтому для загрузки RistOs потребуется совместимая установленная прошивка MineOS EFI или установка/прошивка RistEFI. Учитывайте квоты/ограничения HTTP-запросов на сервере: Lite — около 105 файлов, Full — около 460. Файлы помещаются на диске только если для них есть место.

**Опциональная прошивка RistEFI (если подходящего загрузчика нет):**

```
wget -f https://cdn.jsdelivr.net/gh/USER/REPO@main/Installer/RistEFI.lua /tmp/ristos_efi.lua
wget -f https://cdn.jsdelivr.net/gh/USER/REPO@main/Installer/FlashEFI.lua /tmp/ristos_flash.lua
/tmp/ristos_flash.lua /tmp/ristos_efi.lua
```

Сначала должен завершиться Install.lua. Прошивальщик резервирует старый код EEPROM на выбранном HDD, затем требует отдельное подтверждение `FLASH`. Если прошивка неработоспособна или диск недоступен, компьютер может перестать загружаться; восстановление EEPROM потребует игрового инструмента/другого компьютера. На уже работающей MineOS рекомендован **Upgrade.lua без перепрошивки**.

## Ограничения

- Переименование MineOS не означает создания нового ядра: встроенные библиотеки и приложения частично остаются оригинальными.
- Протестированы структура файлов и параметры сборки, а не выполнение в реальном OpenComputers. Перед массовой установкой протестируйте на отдельном игровом компьютере.
- Установка «из ZIP прямо внутри OpenComputers» не поддерживается: файл ZIP сначала нужно разместить как набор файлов на доступном HTTPS-хостинге.
- Все обращения рассчитаны на jsDelivr, потому что на GravityCraft `raw.githubusercontent.com` не отвечает.

## Обновления

Чтобы в будущем обновлять RistOs через CDN, изменяйте файлы в репозитории и пересобирайте соответствующие манифесты размеров. Для новых релизов предпочтительно публиковать тег, а затем менять URL с `@main` на `@vX.Y.Z`.
