RistOS 0.2.1 — исправление обновления 0.2 для GravityCraft

Предыдущий updater падал с "2826 (expected 2821)" при загрузке Rist Control.app/Main.lua.
Новый обновлятор сохраняет контроль размера и точную проверку для .pic,
а для .lua проверяет заголовок RistOS 0.2 и корректность синтаксиса
перед записью на диск. Для текстов проверяется формат.

УСТАНОВКА:
1. Распакуй папки Installer и RistOS из ZIP в F:\GitHub\RistOS (объединить, заменить файлы).
2. В GitHub Desktop нажми Commit to main, затем Push origin.
3. Открой страницу GitHub и проверь появление Installer/Upgrade_0_2_1.lua.
4. В RistOS запусти MineCode IDE. Создай Lua-файл с содержимым Installer/RistOS_0_2_1_loader.lua.
5. Запусти. После "update completed" перезагрузи компьютер.

Примечание: updater НЕ перепрошивает EEPROM, НЕ трогает OS.lua, загружает
и проверяет все обновлённые файлы до начала замены. Копии старых файлов:
/.ristos-021-backup/. Старый обновлятор v0.2 запускать больше не нужно.

При ошибке на этапе загрузки живые приложения остаются без изменений.
